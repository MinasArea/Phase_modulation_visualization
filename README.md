# Phase Modulation Visualization

An interactive educational visualization platform for understanding **Phase Shift Keying (PSK)** modulation techniques through real-time animations, constellation diagrams, waveform generation, and noise simulation.

# Overview

When I first started studying phase modulation and PSK systems, the concepts felt difficult to visualize.  
I understood the theory mathematically, but I struggled to truly see how phase changes affected the transmitted signal.

To better understand it myself, I built this interactive visualization tool using pure HTML, CSS, and JavaScript.

The project allows users to:
- visualize constellation diagrams in real time,
- observe waveform phase shifts,
- compare multiple PSK modulation schemes,
- and interactively control animation speed.

The goal is to make PSK modulation more intuitive and easier to learn for students studying:
- Wireless Communications
- Signal Processing
- Digital Communications
- Telecommunications

---

# Supported Modulation Schemes

## BPSK
- 2 phases
- 1 bit per symbol
- High noise resistance

## QPSK
- 4 phases
- 2 bits per symbol
- Better bandwidth efficiency

## 8-PSK
- 8 phases
- 3 bits per symbol
- Higher data rate

## 16-PSK
- 16 phases
- 4 bits per symbol
- Demonstrates PSK limitations under noise
